## 2. 今後の自動テスト計画(アプリ本体)

優先度順:

1. DB: 上記 1-1 を SQL スクリプトとして `supabase/` に残し、CI なしでも 1 コマンドで再実行できるようにする。
2. 進捗のビュー: 週の境界(月曜始まり)、完了していないセット、データなしの部位。
3. `lib/utils.ts`: `addDays`(月またぎ・年またぎ)、`toDateString`(ローカル日付)。
