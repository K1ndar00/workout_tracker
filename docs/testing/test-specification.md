### 1-2. `computeProgress`(`shared/stats.ts`)

- ワークアウトなし → 回数 0、PR 空、`maxWeekCount` は最小 1
- 重量 0 のセットのみの種目 → PR に含まれない
- PR は重量の大きい順で最大 8 件
- 種目名が空の種目は無視される
- 週の境界(日曜と月曜)での振り分け ※日付固定のためテストでは現在時刻のモックが必要

### 1-3. `shared/utils.ts`

- `addDays`: 月またぎ・年またぎ
- `formatDayLabel`: 今日なら「今日」
- `uid`: 重複しない文字列を返す

## 2. 異常系・境界値(手動または今後自動化)

| 対象 | ケース | 期待結果 |
| --- | --- | --- |
| 同期 | ネットワーク切断中に編集 | ローカルに保存され、状態は `error` または `syncing`。復帰後に反映 |
