# ユースケース

ユーザーは「アプリ利用者(トレーニーとして記録をつける人)」。以下は既存機能から整理した主要シナリオです。

## UC-01 ワークアウトを記録する

- **ユーザーストーリー**: 今日のトレーニング内容を記録したい。なぜなら、後で重量や回数を比較したいからだ。
- **手順**
  1. 「新規ワークアウト」を押す(例: 「胸の日」)
  2. 種目を追加する(例: ベンチプレス)
  3. セットごとに重量と回数を入力し、終わったら完了にする
  4. 必要ならメモを書く
- **結果**: ワークアウトが一覧の先頭に保存され、自動で同期される。進捗画面の集計にも反映される。

## UC-02 トレーニング計画を作る

- **ユーザーストーリー**: 週ごとのメニューを決めておきたい。なぜなら、その日に何をするか迷いたくないからだ。
- **手順**: 新規プラン作成 → 週の頻度を設定 → Day ごとに種目・セット数・回数を入力 → 使用するプランを有効にする
- **結果**: プランが保存される。

## UC-03 進捗を振り返る

- **ユーザーストーリー**: 自分の成長を確認したい。なぜなら、継続のモチベーションにしたいからだ。
- **手順**: 進捗画面を開く
- **結果**: 週別頻度、今週・今月の回数、種目別最大重量を確認できる(部位別・種目別への特化は今後)。

## UC-04 複数端末で使う

- **手順**: PC で登録・ログイン → スマホアプリで同じアカウントにログイン
- **結果**: 一方で追加・編集・削除した内容がもう一方に反映される(リアルタイム通知・アプリ復帰時・起動時)。
- **例外**: 同じ項目を両端末でオフライン中に編集した場合は、後から同期した側が残る。

## UC-05 オフラインで使う

- **手順**: 電波のない場所で記録する
- **結果**: 端末に保存され、オンライン復帰後に自動で同期される(失敗時は 10 秒後に再試行)。

## UC-06 アカウントなしで試す

- **手順**: Supabase を設定せずにアプリを起動する
- **結果**: ログイン不要で、その端末だけに保存して使える(同期はなし)。
