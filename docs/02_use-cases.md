# ユースケース

ユーザーは「アプリ利用者(トレーニーとして記録をつける人)」。以下は既存機能から整理した主要シナリオです。

## UC-01 ワークアウトを記録する

- **ユーザーストーリー**: 今日のトレーニング内容を記録したい。なぜなら、後で重量や回数を比較したいからだ。
- **手順**
  1. 「新規ワークアウト」を押す(例: 「胸の日」)
  2. 種目を追加する(例: ベンチプレス)
  3. セットごとに重量と回数を入力し、終わったら完了にする
  4. 必要ならメモを書く
- **結果**: ワークアウトが一覧の先頭に保存され、自動で同期される。進捗画面の集計にも反映される。

## UC-02 トレーニング計画を作る

- **ユーザーストーリー**: 週ごとのメニューを決めておきたい。なぜなら、その日に何をするか迷いたくないからだ。
- **手順**: 新規プラン作成 → 週の頻度を設定 → Day ごとに種目・セット数・回数を入力 → 使用するプランを有効にする
- **結果**: プランが保存される。

## UC-02b 種目を選ぶ・追加する

- **手順**: 記録または計画で種目欄を開く → 部位ごとの一覧から選ぶ。なければ「新しい種目を追加」で名前と部位を指定
- **結果**: 選んだ種目が記録に紐づく。追加した種目は種目画面で名前・部位の変更、削除(未使用のもの)ができる。

## UC-03 進捗を振り返る

- **ユーザーストーリー**: 自分の成長を確認したい。なぜなら、継続のモチベーションにしたいからだ。
- **手順**: 進捗画面を開く
- **結果**: 週別頻度、今週・今月の回数、種目別最大重量を確認できる(部位別・種目別への特化は今後)。

## UC-04 通信できないときに編集する

- **手順**: 電波のない場所で入力する
- **結果**: 画面には反映されるが、保存はできず「保存できていません」と表示される。通信が戻ったら「再試行」で保存する(オフライン編集・自動同期はしない)。

## UC-05 スマホで使う

- **手順**: スマホのブラウザで同じアカウントにログインする
- **結果**: PC と同じデータを、スマホ幅のレイアウトで操作できる。
